# Funding Goals

If Lingua OSS receives API credits from an open-source program, the credits should produce public artifacts.

Priority outcomes:

1. multilingual synthetic regression packs
2. published semantic-evaluation rubrics
3. reproducible omission/hallucination/meaning-preservation reports
4. subtitle semantic-boundary evaluation
5. failure-to-regression-test tooling
6. maintainer automation for triage, review, and release preparation

Success should be measured by checked-in code, fixtures, reports, tests, and contributor workflows rather than by private product features.
