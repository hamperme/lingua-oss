# Open-Source Application Positioning

When describing Lingua OSS in grant or maintainer applications, keep the claims narrow and verifiable.

## Accurate current positioning

- new public open-source Swift package
- clean public history separate from a private product repository
- deterministic subtitle and evaluation core
- buildable/tested package with regression tests and a sample CLI
- privacy-first contribution and fixture policy
- early-stage project seeking to build reusable multilingual evaluation infrastructure

## Do not imply yet

- broad ecosystem adoption
- a large contributor community
- high GitHub star/download counts
- production-scale hosted evaluation
- that private product code or private datasets are open source

## Strongest funding case

The strongest case is not "credits for translating an app." It is using credits and Codex to build public multilingual evaluation infrastructure: synthetic regression generation, omission/hallucination/meaning-preservation rubrics, subtitle semantic-boundary evaluation, failure-to-test workflows, and maintainer automation.
